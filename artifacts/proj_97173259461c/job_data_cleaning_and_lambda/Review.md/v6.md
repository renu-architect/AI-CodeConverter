## Key Observations

### What Iteration 2 Fixed Correctly
- **`strip_currency`** — the `regexp_replace` implementation with `when`/`otherwise` null guards is a strict improvement over the original lambda UDF, which would have thrown `TypeError` on null input.
- **`nest_and_cast`** — use of `struct()` rather than dot-notation aliases is the correct approach for Parquet nested column serialisation; dot-notation aliases produce flat column names with dots, not true struct nesting.
- **`write_output`** — `mode("overwrite")` ensures idempotent re-runs, which the original Glue job implicitly relied on via S3 overwrite semantics.
- **Parameter handling** — resolving `storage_account` from `spark.conf` with a fast-fail assertion is the correct Synapse pattern; avoids the `mssparkutils.notebook.run()` anti-pattern.

### Remaining Risk
The **filter/cast ordering issue** (MEDIUM severity above) is the only logic-affecting gap. In practice it will only surface if the source CSV contains rows where `provider id` is a non-null non-numeric string (e.g. `"N/A"`, `""`). If the source data is clean this is a latent bug; if the source data is dirty it produces incorrect output silently.
