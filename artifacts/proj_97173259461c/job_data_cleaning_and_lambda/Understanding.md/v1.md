## Business Purpose

This job performs **data cleaning and transformation of Medicare payment records** sourced from the AWS Glue Data Catalog. It resolves ambiguous data types in the provider identifier field, removes erroneous null records, strips currency formatting (dollar signs) from monetary charge columns using a Python lambda UDF, restructures flat fields into a nested provider/charges schema via field mapping, and writes the cleaned and reshaped dataset to S3 in Parquet format. The output is intended for downstream analytical consumption of Medicare provider charge data.

## Transformations

### 1. Type Resolution — `resolveChoice`
- **Type:** Schema Repair / Type Casting
- **API:** `DynamicFrame.resolveChoice`
- **Detail:** The `provider id` field is detected as a **choice type** (ambiguous between `long` and `string`), a common Glue scenario with inconsistent source data. The resolution strategy `cast:long` is applied — values that cannot be cast to `long` become `null`.
- **Input:** `medicare_dyf`
- **Output:** `medicare_res`

### 2. Filter — `DataFrame.where`
- **Type:** Row Filter
- **API:** PySpark `DataFrame.where`
- **Detail:** Removes all records where `provider id IS NULL`. This eliminates records that failed the `cast:long` resolution in step 1 (i.e., records where `provider id` was a non-numeric string).
- **Predicate:** `` `provider id` is NOT NULL ``
- **Input:** `medicare_df` (post `toDF()`)
- **Output:** `medicare_df` (filtered, same variable)

### 3. UDF Application — Lambda / `withColumn`
- **Type:** Column Derivation via User-Defined Function
- **API:** PySpark `udf`, `DataFrame.withColumn`
- **Detail:** A Python lambda UDF (`chop_f`) is registered as a `StringType` UDF. It strips the first character (the `$` dollar sign) from monetary string columns. Applied three times via chained `withColumn` calls:
  - `ACC` ← `average covered charges[1:]`
  - `ATP` ← `average total payments[1:]`
  - `AMP` ← `average medicare payments[1:]`
- **Risk:** The UDF assumes all values begin with `$`. Any value that is `null`, empty, or does not start with `$` will produce incorrect results or raise a runtime error (see Risks section).
- **Input:** `medicare_df` (filtered)
- **Output:** `medicare_df` (with new columns)

### 4. DataFrame to DynamicFrame Conversion — `DynamicFrame.fromDF`
- **Type:** Framework Conversion
- **API:** `DynamicFrame.fromDF`
- **Detail:** Converts the transformed Spark DataFrame back to a Glue DynamicFrame to leverage Glue-native `apply_mapping`. Frame is named `"nested"`.
- **Input:** `medicare_df`
- **Output:** `medicare_tmp`

### 5. Field Mapping — `apply_mapping`
- **Type:** Schema Transformation (Rename, Recast, Nest)
- **API:** `DynamicFrame.apply_mapping`
- **Detail:** Performs three simultaneous operations across 10 fields:
  - **Renaming:** e.g., `drg definition` → `drg`, `hospital referral region description` → `rr`
  - **Nesting:** Dot-notation in target field names creates nested structs: `provider.id`, `provider.name`, `provider.city`, `provider.state`, `provider.zip`, `charges.covered`, `charges.total_pay`, `charges.medicare_pay`
  - **Type Casting:** `ACC`, `ATP`, `AMP` (string) → `double` for the `charges.*` fields
- **Input:** `medicare_tmp`
- **Output:** `medicare_nest`

### Transformation Summary

| Step | Operation | API Layer | Input Variable | Output Variable |
|---|---|---|---|---|
| 1 | Type resolution (choice → long) | Glue DynamicFrame | `medicare_dyf` | `medicare_res` |
| 2 | Convert to Spark DataFrame | Glue/PySpark | `medicare_res` | `medicare_df` |
| 3 | Filter NULL provider IDs | PySpark | `medicare_df` | `medicare_df` |
