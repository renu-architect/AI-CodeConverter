## Conversion Notes

### Fix 1 — Performance (lines 97–100): UDF replaced with `regexp_replace`

**Root cause:** The original converted code used a Python UDF (`_strip_leading_char`) to remove leading `$` characters. Python UDFs require serialization of each row through the Python interpreter (pickle round-trip), bypassing Catalyst optimizations entirely.

**Fix applied in `apply_currency_strip()`:**
- Removed `_strip_leading_char` UDF definition and all `udf()` registration calls.
- Replaced with three `regexp_replace(col(...), r"^\$", "")` expressions chained via `.withColumn()`.
- `regexp_replace` executes on the JVM inside the Catalyst execution engine, handles `null` natively without a custom guard, and is eligible for predicate pushdown and whole-stage code generation.
