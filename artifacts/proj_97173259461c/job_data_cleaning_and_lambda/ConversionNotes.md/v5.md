The original Glue job maps `provider zip code` as `long→long`, so the output column must be `LongType`. Leaving it as `StringType` breaks downstream consumers.

- A detailed docstring comment documents this design decision so future maintainers understand why the schema declaration and the cast are separated.

### Fix 3 — `transformations` (HIGH, lines 10–18)

**Problem:** `regexp_replace` was imported but never called. The dollar-sign stripping logic (equivalent to the Glue `Map` lambda `x[1:]`) was entirely absent. The original UDF would also throw a `NullPointerError` on null input.

**Fix applied:**
- `strip_currency()` implemented with three `withColumn` calls producing intermediate columns `ACC`, `ATP`, and `AMP`.
- Each `regexp_replace` call is wrapped in a `when(...isNotNull(), ...).otherwise(lit(None).cast(StringType()))` guard to safely handle null values — matching the intent of the original UDF while avoiding the `NullPointerError` it would raise on null input.
- The regex `r"^\$"` is behaviourally equivalent to `x[1:]` for all values that begin with `$`, and is safer for values that do not (it leaves them unchanged rather than silently corrupting them).
- `strip_currency()` is called in `main()` after `resolve_provider_id()` and before `nest_and_cast()`, matching the original Glue transform order.

### Fix 5 — `security` (MEDIUM, lines 43–50)

**Problem:** `mssparkutils.notebook.run('get_param')` was used to retrieve the `storage_account` parameter. `notebook.run()` executes a child notebook and returns its exit value — it is not a parameter-fetching API. This pattern is fragile, adds latency, requires a separate notebook to exist, and silently falls back to the Spark conf path on failure, masking misconfiguration.

**Fix applied:**
- Removed `mssparkutils.notebook.run()` entirely.
- Replaced with the standard Synapse parameter pattern: `spark.conf.get("spark.job.storage_account", "<storage_account>")`.
- For Spark Job Definitions, the pipeline injects the parameter via the Spark conf key `spark.job.storage_account`.
- For Notebooks, the same conf key can be set via the Synapse pipeline parameter cell toggle.
- The `assert` guard is retained to fail fast with a clear message if the placeholder is not resolved, preventing silent misconfiguration.
- The `try/except` block now catches `Exception` with a named variable (`exc`) and logs a warning, satisfying the coding standard requiring specific exception handling and no bare `except` clauses.
